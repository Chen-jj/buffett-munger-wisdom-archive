- 状态：**accepted / NB-09已直接替换为有界双语编辑生成与统一排时；真实固定样片文本/排版已复核，核听/人类出版签字未验证（2026-11-07）**。

## 1. 输入与模块归属

读取已验证的 source alignment、[ADR-0010](0010-source-chunking.md) 候选 chunk、
[ADR-0011](0011-contextual-chunk-translation.md) 首轮译文、媒体边界证据及版本化政策。
校验资产身份、来源指纹、源词覆盖与译文 ID。输入不一致直接失败，不交模型补救。
0010 的阅读预算是估算，不是已经分配的时长；0011 的初译及标题不覆盖。

后处理作为 `translation` 的独立用例，模型提出中文和分组，纯规则试算、验证并决定最终逻辑时间。
新路径中 `srt_processing` 在上游仍负责源语 chunking，在下游只校验并投影最终稿，不另行拆并、
延时或比例分配。后处理输出是唯一权威双语稿，SRT 与 rendering 均从该稿投影；
rendering 负责视觉排版，接入见 [ADR-0006](0006-subtitle-rendering-ass-and-burn-in.md)。公共工件归 `archive_core`；不新增顶层模块，不跨模块
调用私有规则；按 ADR-0008 直接替换旧路径，不保留多套契约或算法。

## 2. 2026-11-07 NB-09 编辑生成修订（取代机械触发方案）

用户授权按专业独立出稿质量调整算法与指标。真实样片表明：消除空帧、满足 CPS 的候选仍可能把
8% 与其归属拆开、移动条件或只改对数字；以机械告警改善作为内容采纳目标，不等价于编辑质量。
本阶段改为对每个完整句组进行有界的双语内容生成，不新增 semantic_alignment 模块、语义评分、
运行时语义审查或自动语义发布门禁。独立 agent 与负责人质量审核仍在集成验收中进行。

| 顺序 | 操作 | 边界 |
|---|---|---|
| 1 | 验证源链、初译、原词覆盖及媒体证据，机械只读试算 | 不先按短 gap 拼接中文，原始初译是编辑底稿 |
| 2 | 完整句组按 180 个 canonical 源词和 50 个初始 cue 分批 | 不拆完整句组、不跨 section；单个超限句组独立发送 |
| 3 | 每批一次编辑生成，结构错误或无解时最多再请求两次 | 模型输出中文及连续源词范围，允许保留已有好稿；不评分 |
| 4 | 从源词重建英文、基本起止时间、全部初译 chunk 来源 | 源词不可增删、乱序或重复；不得伪造词锚 |
| 5 | 用最后分组统一按需延长，再报告全部残余指标 | 不累加试算，不以指标警告拒绝忠实稿或宣称达标 |

该批次限制是控制请求体与覆盖风险的工程参数，不是字幕行业规则。完整原句和说话人 metadata、
当前初译、必要 section 只读上下文、保护跨度、术语及无声学时间的编辑标记分开传递；实际 PTS
留在本地，模型只见现有 word ID、原文与起止时间。额外上下文没有编辑权限。

## 3. 内容、分组与生成权限

优先级为：含义完整与逐屏对应 → 自然口语与有意义的停顿 → 容量及阅读指标。正常英文目标为
80 字符/cue；20 英文 CPS、9 中文 CPS、834–7000ms、中文 16 单位和两帧间隔继续如实测量，
不驱动内容删减、语义提前/滞后或无谓碎屏。最终长度、CPS、时长及非重叠帧间隔均为可报告指标，
不是内容候选的一票否决标准；实际字体、布局、ASS 与媒体安全仍由渲染校验，不据此放宽。

数字、单位、比例分母、比较、否定、条件、例外、程度和口语改口必须保留。并列分项继承同句中
已建立的限定，必要时最小重复该范围，不能把不完全相关说成完全无关，不能把能否实现变成何时实现。
已确认术语按义项本地化；未知名称与缩写保留原拉丁拼写，不音译、扩展或猜改。

模型可提出没有预先列出的词间切点，但不得拆已知保护跨度。跨 section、不同已知说话人或用未知
说话人桥接两位已知说话人均禁止；跨原句合并仍须完整包含每个原句且原始句间 gap 严格小于500ms。
不把一句的前后缀贴到另一句以消除帧间隔，也不移动任何源词的时间。

## 4. 最终排时不变

每条 start 为首词开始，base_end 为末词结束。所需显示时长取834ms与中文计数/9CPS之较大值，
只借所需量；最多向后500ms，并受7秒总时长、媒体末尾、下一源词开始及两个实际空帧约束。
基于现有 ASR 词锚，不额外要求静音证明。已超7秒的源跨度不截断成假合格；无 PTS 时不借相邻
间隙并记录未知。不得提前 start、截掉末词、用平均帧率冒充实际帧证据或累加多次延长。

## 5. 结构复验、额度与未完成状态

响应仍只允许 status 和 cues；每条只含 first_word_id、last_word_id、translated_text。
程序拒绝无效字段、空白正文、窗口外词、漏词、重复、乱序、破坏已知保护/边界、实际重叠或越界。
程序不比较候选是否减少旧告警，不为更差的可读性指标自动重试，也不接受模型的语义自评。
这些检查通过不等于译文准确或出版质量通过。

每批最多3次内容请求，请求前先将额度落盘；中断、提供方失败、格式错误和结构错误均消耗本批
额度，恢复重建同一请求及响应轨迹。源输入、政策、prompt、术语和批次限制绑定生成身份。
改版后的新生成不是旧身份的恢复；旧账本保留，不能用恢复重置新身份的额度。

若三次均无结构合格稿，保留该批原初译，报告 retained_initial_draft=true、editorial_generation=
partial_unresolved 和真实警告，不把它算成编辑完成。其余批次仍可生成；不回退到比例映射、
旧算法或其他提供方。完成状态为生成状态，不是语义签字；semantic_review 始终 not_run。

## 6. 输出与回归

继续发布唯一权威 final_bilingual_draft.json、bilingual_postprocessing_report.json、成功 manifest。
标题沿用初译，源链及时间由程序校验；SRT/ASS 同稿同时间。报告按批记录范围、额度、结构结果、
保留初译和错误，以及全片真实警告。有效复用仍零模型请求、零阶段改写；只读 verify 不探测提供方。

单元/集中离线覆盖批次边界、完整句组/section/超限句组、无告警也编辑、源覆盖/保护/权限、
指标变差仍如实发布、未解批保留原稿但不宣称质量、最多三次中断恢复、篡改账本、最终时锚与零写复用。
旧机械触发/采纳测试的逐项替代理由见 [NB-09 编辑测试映射](../tasks/NB-09-editorial-test-mapping.md)。
