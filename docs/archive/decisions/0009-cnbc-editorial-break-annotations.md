# ADR-0009：CNBC 逐字稿编辑破折号的结构化标记

> 2026-11-17归档说明：已实施的技术方案归档，未被后续ADR明确替代的现行契约继续生效；语义/核听/出版未通过不因归档改变。 原路径`docs/decisions/0009-cnbc-editorial-break-annotations.md`；原状态、历史不commit/push约束及验证结果属于当时记录。后续入口：[NB-12](../../tasks/NB-12-chunking-quality-iteration.md) / [ADR-0013](../../decisions/0013-typed-chunking-quality-and-regression.md)。

- 状态：**accepted / 已开发实现，待负责人完整离线及编排真实产物验收**（2026-11-05）。
  公共source-alignment.v2 annotations与canonical投影已接入，实际声画/全样本尚未审核。
- 日期：2026-11-01（Asia/Shanghai）。
- 讨论范围：仅 CNBC 官网逐字稿中、经过现有融合流程后仍保留的 **U+2014 `—`**。
  不处理 U+2013 `–` 或 U+002D `-`，不讨论其他流水线政策。
- 可能影响：`transcription`、`archive_core`；下游契约需与 translation、chunking/字幕规划及
  rendering 相关设计另行协调。本 ADR 不预设新增模块或插件系统。

## 1. 一句话说明

将融合结果中来自 CNBC 官网的 `—` 从英文单词正文分离，记录为有位置、有来源、无独立
发音时间的辅助编辑标记。来源解释集中处理；后续模块按通用标记契约消费，不各自增加 CNBC 特判。

## 2. 审查证据与根因

历史审查工件（已按 2026-11-05 用户授权删除，以下是当时记录）：CNBC source_alignment.json（历史产物已授权删除；原路径：`../../output/transcription-integration/cnbc_2000_morning/source_alignment.json`）。

- SHA-256：`99f36287d28d0581ae039f64eeea55c14bef044dbb87fdca2f9c8d26ad7fbf91`。
- 文件搜索到 52 个 `—`，实际正文只有 **26 处**：词表和完整句子分别保存了一次。
- 26 处均有官网 token 来源证据；其中 25 处对应 ASR 词没有 `—`，仅 `figures—` 在两边都有。
- 文件搜索到的 24 个 `-` 包括正文的重复表示、schema 名及章节标题；本 ADR 不改变任何 `-`。
- 这是文本和溯源审查，不是核听；符号及词间 gap 均不能证明实际静音。

当前 tokenizer 将非开引号类标点附到前一个词；融合通常选择匹配到的官网表面文本；句子再由
词表重建。因此官网的 `go —` 会成为 `go—`，符号随单词传到下游。
实现依据：[tokenizer](../../../src/transcription/domain/alignment.py)、
[融合表面文本选择](../../../src/transcription/application/fusion.py)、
[句子重建契约](../../../src/archive_core/interfaces/transcription.py)。

ASR-only 保留。词可以正确匹配，但原有中断标点不一定适用于融合后的相邻词，不能直接充当字幕正文。

## 3. 本轮已确认的范围与方向

1. **处理时点在融合之后。** 不改变现有词匹配、官网词纳入/排除及声学时间决策；只处理最终
   融合结果中仍存在、有 CNBC 官网来源证据的 U+2014。融合后不存在的标记不恢复、不补位置。
2. **词与辅助标记分离。** 不再把它作为 `go—` 的词尾正文；`go`、`ahead` 的词身份、顺序和
   时间保持。标记不是一个 spoken word，不新增普通 word ID，也不伪造独立声学时间。
3. **使用结构化标记，而非另一个特殊字符。** 暂用名称 `editorial_break`，表达“官网编辑者
   标记了表达结构变化”；不自动断言是停顿、改口、重启或插入语，不细分未经核听的类别。
4. **最小来源策略。** CNBC 解释逻辑集中在转录的逐字稿处理边界，来源证据随标记传递；
   下游面向通用标记类型工作。非 CNBC 来源和 ASR 独有符号不自动套用，不依据目录名猜来源。
5. **算法不改变现有声学决策。** 历史集成文件已按 2026-11-05 授权删除；编排完成后完整生成
   新媒体与转录。当前不提前运行昂贵阶段，不能手改 JSON 后继续沿用不匹配的 manifest。

“在 CNBC 逐字稿阶段标记”指上述逐字稿解释能力的归属，不要求在官网文本解析时就确定最终
word 位置；用户明确选择只看融合后的保留结果，因此无需为被排除的官网标记建设映射恢复流程。

## 4. 公共表示示意：不是已冻结 schema

英文正文可读作 `go ahead.`；辅助信息独立传递，评审界面可以把该位置显示为 `go [标记] ahead.`。
以下只是最小候选字段，不代表现有 schema 已支持，也不授权向 v1 直接增加字段：

```json
{
  "kind": "editorial_break",
  "after_word_id": "w138",
  "origin": "official_transcript"
}
```

对应英文词仍有原 word ID 和时间。实际契约还需确定标记身份、官网 token 引用、来源策略版本、
首尾位置及序列化方式。词表与句子必须能按新版规则一致重建，不能只修改 sentence.text。
公共 DTO、schema、manifest 与缓存身份的具体版本号待接口评审后确定；不放松旧解析器。

## 5. 新路径下游交接（未实施）

句法、计数、导出统一使用无目标辅助标记的正文。初译与修订单独接收相关标记，仅作参考。
完整集成重新生成媒体、ASR 与融合证据，据此发布现行 alignment；不建设旧格式转换。
缺必要来源证据则不猜测标记。

| 消费环节 | 新路径处理方式 | 实施时验证 |
|---|---|---|
| 翻译输入 | 单独提供标记及解释，作为口语结构参考；不逐符号翻译，不在中文里保留该辅助符号 | 输入格式、prompt、上下文范围、如何校验模型未因去符号而丢失限定或修正 |
| 初次机械 chunking | 不用标记生成可选断点，也不纳入切分评分 | 与未来 chunking 输入/句法分析的接口，如何确保辅助信息没有经正文标点间接影响切分 |
| 问题 cue 的后处理 agent | 可参考标记，提出切分、合并或移动边界建议；不能把标记等同于合法切点 | 触发条件、允许操作、机械保护规则及修订边界，均留待后续流程讨论 |
| CPS、长度与排版 | 辅助标记不计入正文指标 | 各阶段采用哪份正文投影及其版本 |
| 最终英文 cue | 不保留该辅助标记，不删除英文词、不一律替换为逗号 | 源正文与 cue 正文的一致性证明、空格处理以及 plan/SRT/ASS 共用规则 |
| 发布验证 | 标记不得意外泄漏为字幕正文；候选为泄漏时阻止正式发布 | 检测层、错误语义及修订路径 |

模型即使利用此标记，也不能改源词或其时间。`go [标记] ahead`、`impossible [标记] to figure`
不能仅因为存在标记就被切开。`all ... [标记] virtually all ...` 的修正含义不能随符号一并丢失。

## 6. 实施前冻结项与交接边界

- 最终公共标记名称、字段、唯一身份、官网 token 溯源及合法位置校验。
- 在现有融合之后、canonical 发布之前的准确接入点，以及来源策略如何通过公开接口选择。
- source_alignment、sentence 重建及下游输入的直接替换方式（不留旧版解析器）；不默认必须引入独立新工件或模块。
- 上表各下游行为的具体字段、错误诊断与验证用例。
- 标记规则、prompt、投影规则的缓存失效范围：变化应沿真实依赖传播，不应使音频/VAD/ASR/
  声学对齐缓存无故失效；旧成功产物不得被新规则静默复用或覆盖。

不在本 ADR 内决定：整体字幕流水线、模型选择、CPS/行数/时长政策、借时间、一般口语清洗、
其他来源的破折号、集成测试迁移或样片生成；不引入 ADR-0007 的独立语义阶段；编排依赖见 ADR-0008。

## 7. 未来实施的最小验证要求（本轮未实施）

- 以本节 26 个位置验证分离结果；英文词 ID、顺序、词时间及来源证据保持，正文只移除目标辅助符号。
- 新版词表、句子和 annotation 的重建/往返一致；不能重复插入标记、生成空单词或把标记变成 timed word。
- 覆盖非 CNBC、ASR-only `—`、U+2013 `–`、U+002D `-` 不受影响；融合中已排除的官网标记不恢复。
- 将 `go— ahead`、词内连字符、多个标记及句尾标记作为专门回归；不按 26 个 ID 硬编码规则。
- 下游行为定稿后再增加翻译/切分/导出验证；结构成功与翻译语义质量分别验收，不能用标记移除宣称语义同步已修复。
- 新版 manifest/cache/reuse 和旧资产保全验证；所有昂贵调用及新样片仍须另行授权。

本轮交付仅为讨论稿及导航，不修改生产代码、prompt、schema、配置或资产，不生成新字幕/媒体。
