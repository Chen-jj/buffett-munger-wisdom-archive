# ADR-0018 以官网优先修订 CNBC 逐字稿融合裁决

- 状态 **已实施，用户确认融合算法通过**。保留单项口述恢复和未核听片段的质量记录。[NB-16](../tasks/NB-16-cnbc-fusion-official-priority.md)
- 日期 2026-11-26（Asia/Shanghai）
- 实施基线为 [ADR-0016](0016-cnbc-timed-transcript-fusion.md) 和 [NB-15](../tasks/NB-15-cnbc-timed-transcript-fusion.md) 的 `run-fusion-2`。句界策略由 ADR-0017 单独记录。

## 背景与目标

NB-15 两场回放已通过词时间、来源和缓存的技术验收。用户随后核听发现，逐词补入会把 `does not have —` 截成 `not`，同窗比较的空路径会误删真实的 `that` 和 `people`，金额也会因旧切点失效而落回相差三个数量级的 ASR 值。核听同时确认官网的 `in middle extended` 与口述一致，说明流畅度不足以判定该采用哪一路。 [独立技术验收](../../../output/cnbc-2020-adr0016-20261126/run-fusion-2/独立验收.md) · [回放前后审阅](../../../output/cnbc-2020-adr0016-20261126/run-fusion-2/融合前后审阅.md)

先减少金额、否定、人名和关键用词错误，再尽可能恢复真实说出的重复、弱读和自我修正。官网文字即使经过轻度编辑，仍是同一位置的优先候选。用户核听结果用于校准和验收，推理规则使用文字、来源及声学证据，样例的资产、时间、姓名和金额只进入测试与审阅记录。

## 拟议裁决

### 1. 先确认位置，再确定写法和时间

- 以单调、相互独立的共有词匹配定位同一段口述，再对齐等价写法、官网增词、ASR 增词及同位冲突。按相邻**可靠共有词**分出连续差异区域，插入和删除视为读法之间的完整差异。弱匹配、重复出现或切点不稳定的共有词不能把同一差异拆开。
- 最近的共有词切点可信时直接使用。切点过窄、低分或两候选无法放入时，在同一说话轮次内向外搜寻可靠共有词，限于现有局部窗口和搜索预算。先在外窗对共有上下文限界，确定一套共同切点，再用同一声学帧比较两种完整读法。候选不得各自借用共有词或其他重复口述的时间。可在有声学依据时更新局部共有词切点，差异与受影响的共有词作为一次提交校验，区间之外沿用原时间。
- 文本能定位、时间仍不可靠时允许记录已选写法和对齐失败的原因，`words` 保留有来源和时间的回退结果。已验证的官网冲突优先仍受时间约束。没有定位到唯一口述时，继续采用既有回退规则并明确诊断为定位失败。

### 2. 等价表达与同一人名优先定稿

- 日期、年代、分数、百分比和金额按两边独立解析。确认类型、数值、单位、币种及相关精度等价后，按项目格式定稿并复用完整声学范围。例如 `100% / a hundred percent` 输出 `100%`。金额的读法比较和输出格式分开，`million / billion`、不同日期顺序或不同单位继续做实际冲突判断。
- 人名先确认同一所指。已有同位对齐与独立的姓名区间，再检查匹配的名字和称呼、引介上下文、结构化人物或发言者标签，以及重复引介是否共同指向同一人。身份得到支撑时采用官网规范拼写，复用实际姓名的发声时间，保留两边的来源。不清楚是否为同一人时按普通冲突处理。发言者标签只用于确认姓名拼写与身份，这一判断不改变说话人段落归属。

### 3. 官网独有的连续片段全插或全不插

- 在一个可靠定位的差异区域内，把连续官网独有词作为一个候选。以同一共有上下文比较含完整片段和省略完整片段两种读法。应覆盖句中、句首和句末，句首或句末可用句内锚和另一侧已有的可靠时间边界限界。
- `0.20` 作为逐词快速通过条件。片段中每词都过线、有独立且保序的声学区间、整体适配且未占用共有词时，可整段写入。有低分词时，允许用重新确定的共有词切点比较完整候选。只有完整片段有正面证据、低分词也有独立时间且未依赖硬拉路径时，才允许整段写入。整段高分由少数高分词撑起、没有独立时间、词序或边界失效时，全部排除并记原因。单个官网补词继续使用 `0.20` 及独立时间检查。
- `does not have` 在现有主窗中的分数为 `0.158 / 0.335 / 0.043`。这组旧分只能复现错误，不能证明新方案已经恢复三词。完整片段若仍取不到可靠证据，回退为整段省略，并把核听用例记为未恢复。

### 4. ASR 独有词用完整口述片段复核

- `≥ 0.50` 且已知有独立声学区间的词直接保留。低分或可能与相邻词共用同一发声时，在同一窗口比较包含与省略该差异的完整读法。重复词比较一次和两次出现，每次都检查是否解释了独立发声并落在相应位置。相邻共有词受保护，可通过共同的局部重新定时查清原先是哪一次被映射。
- 只有删后的完整读法更好解释同一段音频，且删去的部分缺乏独立发声支持时才删除。仅靠空路径胜出、平均分低或官网未写该词，证据不足。对连读或弱读导致的对齐歧义，保留已有时间的 ASR 词，记录复核结果。删除仍保留原 ASR ID 与时间用于对账。

### 5. 同位冲突由官网优先，强反证才改用 ASR

- 同窗整段 CTC 用于比较候选，关键差异词的声学支持、未解释的发声和切点扰动用来核实结果。改变裁决须有稳定优势，ASR 必须正面解释真正相异的词或音节，且不得靠挪用共有词或其他发声取得优势。能量覆盖与字符均分是辅助指标，语法流畅度只用于安排抽查。
- 官网读法并无强反证时，定位与时间通过校验即可定稿。个别字母弱、候选分数接近、或切点小幅变化令优势翻转时，不单凭该分数采用 ASR。改变否定、数值、数量级或身份时，强反证必须落在能改变含义的词或数值成分上。
- 比较金额时，在两边一致允许等值读法，例如 `a / one`、可省略的 `and`，以及币种可由上下文唯一确定时省略或念出 `dollars`。末级数量成分含混时，记录音频支持的数值层级及剩余歧义，不将两个不同精确值归为等价。Part1 这例的用户核听支持 `a billion … one hundred and seven million …`，未明确听到末尾 `thousand`。同位发声与时间验证通过、没有明确互斥的完整金额证据时，采用官网 `$1,107,400,000`，诊断如实保留精度差异。需要放宽旧窗时，金额必须落在重新校验过的 `put` 和 `or` 之间。 [已有固定窗及扩窗诊断](../../../output/cnbc-2020-adr0016-20261126/diagnostics/part1-fixed-window-calibration.json)

## 备选与取舍

| 选项 | 取舍 |
| --- | --- |
| 只调整逐词或整段分差门槛 | 改动小。真重复、误重复、真官网增词和误插在现有分数上有交叠，无法解决差异组只插部分或者窗口本身错误。 |
| 可靠匹配后整句采用官网并复用 ASR 时间 | 更接近官网写法。但句首、句尾及真实漏词的时间可能无法复用，也会掩盖有强音频反证的错词。 |
| **同位定位后按差异类型裁决，并对完整候选做有界复核** | 能保护官网的语义和真实说出的细节。对不可靠切点多做少量局部对齐，需要保存可复现的证据，并在验证集上标定强反证与整段补词的门槛。 |

## 影响范围与可观察证据

- `transcription` 的融合领域规则负责差异分类、等价和选择，应用层负责局部候选与发布校验，现有本地强制对齐端口提供同窗证据。复用已存音频、VAD、raw ASR、整场词对齐及已修复的 CNBC 章节。编码清洗、单一 `words` 正文、时间与来源契约继续沿用 ADR-0016。句界、chunking 及后续阶段按各自契约处理。
- 日志应能回查差异类型、上下文锚和原切点、实际比较窗与两边读法、用于判定的分差和关键差异证据、选稿原因及回退原因。`words` 只写正式结果。已有诊断字段可继续使用。差异区间调整不得引入越界、重叠或来源重复。融合身份绑定新决策版本和参与决策的配置，上游身份保持可复用。

### 复现步骤与通过标准

1. 先用定向离线用例验证全插全不插、低分时的完整候选复核、强反证与弱证据的分支、金额和人名、重复删留、时间与来源边界。随后运行 `.venv/bin/python -m pytest tests/ -q -m 'not live'`。用已存声学证据或端口替身复现低分、歧义、切点过窄和两种候选均不可对齐。找不到真实正例的分支用离线用例覆盖。
2. 获得本轮真实回放授权后，依据 [ADR-0008](0008-local-orchestration-and-integration-tests.md) 在新工作区仅执行两场的融合，复核实际输入与基线哈希。以表中时间和前后共有词定位差异，逐项查新旧 `words`、来源 ID、逐词时间和比较窗。已知误读与漏词应通过表中质量验收，安全回退单独报告。全量复核单一正文、边界、ASR 和官网来源对账，以及同配置复用零额外对齐、零工件改写。
3. 在规则和阈值固定前准备另一组未参与调参的核听片段。对照同样的旧稿、新稿和独立核听标注，分别记录语义错误、口述细节恢复、退化和未定项。已核听样本要求新增重大语义错误为零并保住已确认正确用例。留出片段支持局部质量判断，整体准确率仍取决于核听覆盖。人工审阅稿应列原视频时间、改前和改后上下文及待听点，另附基于两份实际 `words` 的全量对照。

## 待决定与标定

- `0.20`、`0.50` 继续作为既有快速通过值。低分多词片段的整段补入阈值、足以推翻官网的分差和关键差异证据，用真实标注与独立留出例验证后确定。验证要覆盖短词、不同长度读法和大小金额。逐词均分、空路径分差和语音覆盖各自记录，便于判断哪项真正区分口述。
- 定向评估外窗重新定时的范围与成本。比较必须遵守现有局部窗口上限和章节边界，任何需要扩大预算的情形单独记录依据和验证结果。
