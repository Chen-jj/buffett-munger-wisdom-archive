## A. 独立agent全量创作

- 创作者使用新上下文，只读上游文本/词时间及明确实验规则，不读现有planner、算法cue/SRT/report或其断点。
- 根指南可能提及历史质量例子，故仅声明未读基线切分，不称严格双盲实验。
- 每个cue的英文word范围与中文片段由agent逐项直接决定，覆盖全部97句，不只修几个案例。
- 禁止调用现有planner、DP或另写自动切分器，也不能用字符比例、机械标点切分、一句一cue等程序规则代替agent决策。
- 脚本仅允许准备紧凑输入视图、按人工指定范围重建、精确偏移/守恒验证、计数、统一时间投影和SRT序列化；原始agent断点决策文件必须保存。
- 不改写/压缩/补译中文，不修改英文或源词时间；所有word与规范化中文字符按原顺序恰好覆盖一次，句内两种语言终点对应，每个fragment双语非空。
- 不跨section、同cue至多一种已知speaker，null原样保留；不重推speaker。开始/基础结束锚定首末词，无重叠/越界，显示最长7000ms。
- 现有16加权中文/42英文容量作为审计项而非强制创作门禁；不得以更大容量的结果冒充同约束算法胜出。
- 固定断点后可用同一纯时间投影规则物化，不能借此重新选择切分；不做视觉换行或样式/烧录。

## B. 全量比较与独立审计

- 保存基线快照/hash与全部原始agent决策；生成agent plan和三份SRT，明确实验schema/provenance，绝不冒用正式DP算法身份。
- 验证全文/ID/范围/时间/speaker/section/原输入不变，格式回读一致；违规不得静默修正。
- 全量指标：cue数量、时长分布、过短、CPS、每种容量超限、英文/专名内部切分等；主观中文词组/意群与中英语义对应须单独逐句审读，不伪装为自动语义证明。
- 对全部97句形成对照记录，记录agent胜/平/负、具体理由和容量/契约差异。不得只挑好看的案例，不以cue少为唯一质量标准。
- 分类：同约束可改好（算法候选/代价问题）；依赖放宽容量才改善（profile/显示预算问题）；固定译文重排+单调共享时间轴导致残余错位（契约问题）；仍有agent失误（参考稿不是金标准）。
- 交付实验README、机器可读指标、全量逐句对照、代表性案例报告与修复优先级/验收建议。修复仅提出方案，本任务不改生产实现。
