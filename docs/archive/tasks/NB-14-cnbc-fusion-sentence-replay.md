# NB-14 CNBC 2020 融合与句界恢复

依据 [ADR-0015](../decisions/0015-cnbc-transcript-fusion-and-sentence-boundaries.md)。使用 Part1、Part2 现存声学与官网工件验证。新产物写入独立的 `output/` 子目录，基线工件保留。授权阶段为逐字稿融合（包括局部补词声学验证）及句界恢复。

| 切片 | 依赖与分工 | 可改路径和验收 |
|---|---|---|
| 融合 | 实现子 agent。依赖本地 ASR 与官网结构化逐字稿。 | 融合领域、应用、接线、相关公开契约和定向测试。保留有证据的词级时间。新增整句选稿、标点、边界锚与局部补词样例。定向用已有输入和替身验证，无联网或实际长片调用。 |
| 句界与日志 | 实现子 agent。离线可独立于融合开发，库存真实验收依赖融合输出。 | 句界、观测性、接线所需的定向修改及测试。验证无 80/200 词强切，无 fallback 数量和比例发布门槛，长日志全文可读回，保住明确换人、章节和可靠标点。 |
| 真实运行准备和对照 | 独立子 agent 准备在隔离工作区验证缓存和调用两个阶段，提供对照工具。负责人在离线验收通过后正式执行。 | 运行和对照代码仅放本轮忽略的输出目录。用实际声学时间和来源映射比较文字及断点，完整表格包含所有差异并可追溯到前后工件。 |

仅在所需阶段内执行真实处理。采集、下载、整场 ASR、整场词级对齐、翻译、字幕导出和烧录不属于本任务。保持原声学工件和已烧录成片的身份与字节。运行前核对局部模型已在本机缓存，验收记录保存调用计数、原始工件校验及真实工件路径。

融合信封升版影响渲染输入的来源校验，允许同步更新该处校验、测试工件与模块指南。实际字幕内容和排时由现行最终双语稿契约决定。

负责人审查每份 diff 后独立执行 `.venv/bin/python -m pytest tests/ -q -m 'not live'`。通过后再分阶段核对真实融合、句界工件，并请独立子 agent 复核真实样例、覆盖与比较表。区分工件/契约验收与人工核听范围。
