# NB-15 CNBC 带词时间的逐字稿融合

依据 [ADR-0016](../decisions/0016-cnbc-timed-transcript-fusion.md)。以 NB-14 工作树和 `run-accepted-1` 两场工件为基线。本轮用户要求推动落地，先实施规则已明确的 CNBC 编码清洗。

## 1. 采集与库存章节使用同一清洗规则

- 依赖 `acquisition.transcript.v2` 公共 DTO、现有 CNBC HTML 正文解析和 [Part1](../../../output/cnbc-2020-adr0015-20261125/run-accepted-1/cnbc_2020_part1/chapters.json#L198)、[Part2](../../../output/cnbc-2020-adr0015-20261125/run-accepted-1/cnbc_2020_part2/chapters.json#L2849) 的章节输入。
- 实现子 agent 修改 CNBC 解析、采集公开入口和采集单元测试。库存通过接收和返回 `StructuredTranscriptDTO` 的采集接口应用相同规则。负责人检查 diff，使用两场基线章节和 ASR 词时间执行无模型的定向核对，再运行完整离线套件。
- 运行 `.venv/bin/python -m pytest tests/acquisition -q` 和 `.venv/bin/python -m pytest tests/ -q -m 'not live'`。HTML 和库存正文均还原指定的编码片段，处理幂等，章段顺序、正常标点和非口述标记保留。Part1 `didn’t` 应匹配 `aw1450` 并复用原词时间。库存回放时在新工作区落盘，记录原文件及修复后 SHA-256，融合绑定新文件身份。
- 转录继续读公共 DTO，清洗逻辑留在采集。保留 NB-14 工作树改动及基线文件。模型与真实回放按 ADR 单独核对授权。

2026-11-26 阶段验收。采集单元测试 47 项通过，负责人独立运行完整离线套件为 **2892 passed / 1 skipped / 6 deselected**。两场库存正文分别修复一处弯撇号，以及一处弯撇号与两处省略号。离线规划将 Part1 的 `didn’t` 匹配至 `aw1450`，复用 `692861–693021 ms`。重新计算两场原输入和旧融合 SHA-256，均与 NB-14 回执一致。

## 2. 带声学时序的融合

用户已授权在新目录复用 NB-14 的两场上游工件，使用本地缓存模型重跑融合。实际运行止于 `transcript_fusion.json`，由独立验收 agent 审阅实际发布词。实现内的句界与渲染衔接仅验证所需的离线契约，句界策略待另议。

| 工作 | 依赖与分工 | 可改路径和验证 |
| --- | --- | --- |
| 固定窗口对齐 | 实现子 agent。依赖已有 WhisperX 模型解析和明确的单窗多候选端口。 | `transcription` 声学对齐适配器、端口和定向测试。以同一份帧输出计算候选整段 CTC、路径时间、字符摘要和能量覆盖。用替身检查同窗模型调用、空候选及重复字符，再用库存的有界片段核对 `lethal / many`、姓名、金额。明确能量指标的使用限制。 |
| 定位、等价与差异发布 | 实现子 agent。依赖清洗切片和固定窗口评分端口。 | `transcription` 融合领域、应用、组装及定向测试。用保序且局部唯一的锚界定同一段口述，判定数值等价后再校验差异。替换和补词使用取得的词时间，不满足证据的保留 ASR 或排除官网词。检查大小失配、时间不变量及来源对账，单一正文为 `words`。临时判定值只用于本轮回放和诊断，记录未校准情形。 |
| 工件契约与隔离运行 | 实现子 agent 处理信封及下游读取验证。负责人审查 diff、运行离线套件并执行两场回放，独立 agent 核验。 | 更新变更涉及的融合缓存、渲染信封校验和模块指南。正式回放使用已核 hash 的上游工件和修复后章节，保留原产物。保存模型与输入身份、调用计数、局部诊断、逐差异 `words` 对照。禁止执行真实句界、分块、翻译、烧录及重新生成上游。 |

负责人验证命令为 `.venv/bin/python -m pytest tests/ -q -m 'not live'`。真实验收按 ADR 时间和来源定位逐例检查，单独记录已确认改善、退化、待核听和缺少样本的分支。

隔离回放使用 NB-14 的三词锚和 `0.50` 锚点门槛，补词使用 ADR 的 `0.20` 试跑门槛。Part1 `aw11123` 起的局部区域含 50 个 ASR 词、6 个官网词，24 词窗口预检会停止。回放显式使用 64 词 DP 上限，参数进入融合身份。局部声学窗口另有独立时长上限。

## 回放准备与离线证据

- 2026-11-26 负责人完整离线套件 **2917 passed / 1 skipped / 6 deselected**。覆盖同窗候选、切点扰动翻转、无重叠时间、部分补词、ASR 排除对账、数值等价与融合 v3 信封。现有句界读取仅改为接收来源 ID，实际回放止于融合。
- [13 个固定窗口校准记录](../../../output/cnbc-2020-adr0016-20261126/diagnostics/part1-fixed-window-calibration.json) 绑定 NB-14 音频 SHA-256 和本机模型快照。五个窗口均支持 `lethal`。姓名主窗口的模型分数支持 `Bosonic`。金额的旧相邻切点使两种完整读法均无法评分，独立重新定位共有词后，诊断窗口支持 *billion*。共有词重新定时尚未进入生产裁决。
- [融合回放入口](../../../output/cnbc-2020-adr0016-20261126/tools/replay_fusion.py) 仅调用融合服务。运行命令为 `PYTHONPATH=src .venv/bin/python output/cnbc-2020-adr0016-20261126/tools/replay_fusion.py run-fusion-1`，回放目录须此前不存在。

首轮独立验收发现书面金额作为补词时未转为可对齐读法，整组会失去声学结果。还发现未独立定位的连续 ASR 差异内，按单词与空读法比较会丢失数字词。由实现子 agent 定向修正补词投影和 ASR 独有词删除范围，验证已有单词证据、整数量词时间及 `aw558` 的独立复核。修正后另开回放目录，保留首轮证据。

两场首轮分别写出 15,491 与 20,402 个融合词。独立验收各完成 33 项工件检查。错误编码、部分数字等价与补词已有改善，两场共四个 NB-14 补词未保留原位置。`Bosanek` 和 `$1,107,400,000` 仍未进入正文，整体口述质量待核。首轮在年代等价末次修正之前载入代码。[首轮独立验收](../../../output/cnbc-2020-adr0016-20261126/run-fusion-1/独立验收.md)

修订版匹配算法为 `monotonic-local-dp.v5`。完整离线套件 **2924 passed / 1 skipped / 6 deselected**。第二轮命令使用同一入口并将目录参数改为 `run-fusion-2`。回执携带融合实现文件指纹，执行期间检测到变化会停止验收。
